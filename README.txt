CAREPOINT HOSPITAL MANAGEMENT SYSTEM
====================================

How to run:
1. Extract the ZIP file.
2. Open the Hospital-Management-System folder.
3. Double-click index.html, or open it with VS Code and use Live Server.
4. Demo login:
   Username: admin
   Password: admin123

Features:
- Login/logout demonstration
- Dashboard statistics
- Patient add/edit/delete/search
- Doctor add/edit/delete/search
- Appointment add/edit/delete/search
- Billing add/delete/search
- Browser LocalStorage persistence
- Responsive layout

Important:
This is an educational front-end demonstration only. It does not use a secure backend,
real authentication, database server, or production-grade patient-data protection.
Do not enter real patient or medical information.
